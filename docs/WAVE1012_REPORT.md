# Wave 1012: consistent team greyscale

All six team portraits now use the same neutral, full-greyscale treatment. The shared DirectorCard applies Tailwind's grayscale utility directly to each image in all five supported card variants. The current About page uses the vertical variant. There is no colour restoration on hover, filter animation or added JavaScript.

The original image files, current crops, Callum's subtle portrait edit, names, roles, experience and surrounding brand colours remain unchanged. Other website photography is outside this team follow-up and is unchanged.

The existing GitHub Actions release workflow supplies mobile and desktop team screenshots plus the website's normal browser, interaction, accessibility, scrolling, motion and contrast checks. No extra test suite, local build, local tests or local browser captures are introduced for this presentation change. Final visual review and public markup, stylesheet and portrait-file verification are recorded in Live-State and local 05-Artifacts/website-team-greyscale-2026-11-05/.
