# Wave 1039: transparent property service pricing

The pricing page replaces Coming soon with the owner's Silver, Gold and Platinum service charges. Silver offers sourcing or lease facilitation separately, each from £5,000. Gold combines them from £10,000. Platinum adds full pre-acquisition project management, including contractor coordination, from £12,500. No monthly subscription, discount, popularity claim or project-management surcharge is invented. Calls to action open the existing investor enquiry route without submitting anything.

The owner confirmed that VAT is not applicable, the sourcing minimum is £5,000 per individual property, and the public lease facilitation rate is 5%. Only those public terms are included in the website. Each package and estimate carries the tax treatment; the introduction expands Value Added Tax on first use. The 5-year minimum calculator term follows the existing public lease-service wording. Rental inputs and the Blackpool example are illustrative, not verified current market rent data.

The interactive estimates are separate services. Sourcing uses £5,000 divided by three times the bedrooms in one property, with the minimum applied and rounding only after the calculation. Lease facilitation uses weekly rent per bedroom times bedrooms times 52 weeks times lease years times 5%, with its £5,000 minimum. All monetary arithmetic uses integer pence until final rounding and rejects unsafe integers, blank/negative/zero values, fractional bedroom counts, excessive monetary precision and unsupported lease terms. The supplied example yields weekly rent £1,104.60, annual rent £57,439.20, five-year rent £287,196.00 and a fee of £14,359.80. Gold and Platinum remain property-specific quotes rather than inferred package calculations.

The light page keeps the existing typography, colour tokens, disclosure interactions and navigation. Package cards provide brief hover and keyboard-focus feedback. Calculator controls are labelled, respond to keyboard/touch and announce updated estimates. A Use this example action restores the Blackpool values and moves focus to the calculator heading. With JavaScript disabled, controls are disabled honestly while package prices, formulas, default estimate, example and native disclosures remain readable. Reduced-motion users receive no new transitions or entrance effects. No scroll handler, continuous animation loop, external calculator request or new dependency is added.

Existing Actions browser journeys now check the published amounts, tax wording, sourcing minimums and rounding, invalid inputs, the Blackpool calculation, lease minimums, changed terms, example reset, contact links, four widths, no-JavaScript and reduced-motion behaviour. Firefox and WebKit check both default estimates. Existing full-page and contrast checks cover pricing.
