# Wave 946: more deliberate public website design

Repeated card grids, draft concept labels and oversized decoration made the site harder to scan. This change gives each page a clearer reading order and introduces interactions that expose useful existing information.

- Home: compact role directory, accessible housing need/response tabs, sourced figures in readable rows, clearer map context and dated platform snapshot.
- Services: one keyboard-accessible tool explorer replaces three competing concepts. The screenshot preview remains; lease comparison uses native disclosures. Draft option labels and simulated activation language are removed.
- Solutions: one layer selector brings each stage, its responsibilities and partner links together.
- About and Problem: quieter real-team profiles, company responsibility rows and sourced evidence tables replace decorative panels and duplicated statistics.
- Partners: stage filtering combines with search, introductions use full-colour photos beside text, and relationship controls reveal existing descriptions. The central IIG ecosystem and diagram viewer remain.
- Contact: compact enquiry selection, clearer contact/support rail, earlier form and flat FAQ disclosures. Switching enquiry preserves an unsent draft.
- Registration and Legal: compact progress and role lists, independent password visibility, readable company records and copy controls.
- Shared surfaces: softer shadows, static informational panels and simpler footer registration records.

All image files, real team portraits, brand palette, hero teal #267977, sourced figures and legal content are preserved. The signed-in platform, form endpoints and authentication are outside this change. The homepage's recorded figures now say `Platform snapshot recorded 3 August 2026`, using the date already documented in their source.

Validation is assigned to GitHub Actions, per the 3 November project instruction. The existing whole-site responsive/accessibility, ecosystem and strict rendered contrast gates remain. Browser coverage now also exercises mission and tool tabs, layer responsibilities, combined partner filters, relationship selection, preserved contact input, keyboard FAQ controls, independent password visibility and company-record copying. Tests block real submissions. No local tests, build, audit or screenshots were run. Deployment and public verification results are recorded in Context Library Platform/Live-State.md and Platform/CI-Runs.md after the run.

The first full Actions run held deployment on an ambiguous contact-test label and reveal probes targeting sections that are now static. The selector now identifies the combobox; the unchanged throttled hydration assertions target Legal and the registration directory, where Reveal is still above the fold. All rendered colour samples passed in that run. Screenshot review also corrected guide-caption overlap, mobile progress spacing and responsive source sizing for cropped partner photographs. The final run covers those fixes together.
