# Wave 1324: hologram Buddy

This report describes the implemented source and its reviewed boundaries. Exact final CI, publication and live observations are recorded in the Context Library's `Platform/CI-Runs.md` and `Platform/Live-State.md`; the candidate outcomes below do not independently establish a live release.

## Result

The website uses the same Blender-authored 3D key, pound and heart as the logged-in platform, rendered through OGL. The rig has separate anatomical left and right hands and positive scales. The new material provides translucent cyan surfaces, scan bands, edge light and opaque facial details. Authored poses include a foreground thumbs-up and an approaching magnifier with an enlarged eye. The supplied v2-refined package remains the identity reference.

There is one persistent website actor. Its interrupted flights retain velocity and settle into corner, page, chat and inspection destinations. Page sections still choose the form. The new page-detail action reads visible published text, enlarges it beside the original and directs the same Buddy to it. It never reads a form field or asks the model to invent a figure. Changed or hidden source text dismisses the reading aid. Escape, keyboard focus, short viewports and route changes have explicit handling.

The chat header remains Buddy. A small magnifier button opens page inspection; a complete typed request to explore page details does the same. A short thank-you receives the authored thumbs-up after an accepted answer. Typing, closing or clearing interrupts the reaction. No animation menu, play/pause button or ball scene is added. Existing bone-white surfaces, Tailwind, provider logos, local-authority carousel and pricing state remain.

## Verification and provenance

Blender previews are asset-authoring output. Application tests, builds and browser checks run only in GitHub Actions, following R-OP-1103-22. The existing decoded-JavaScript and frame budgets remain unchanged.

CI checks the actual production renderer and GLB, all three forms, front/profile/back views, six form transitions, close-ups, construction, anatomical hands and the published-page inspection journey. The production source hashes are captured with the diagnostic bundle. Existing website journeys continue to check a single canvas, chat cancellation, model failure, hidden/reduced motion and viewport overflow. GLB structure and animation channels are checked separately from changing shader pixels.

Framework: [OGL](https://github.com/oframe/ogl), version 1.0.11, Unlicense. Authoring: Blender; authored character source and manifest are kept with the platform. No hosted design subscription or remote asset-generation service is required at runtime.
