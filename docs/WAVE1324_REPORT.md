Changed or hidden source text dismisses the reading aid. Escape, keyboard focus, short viewports and route changes have explicit handling.

The chat header remains Buddy. A small magnifier button opens page inspection; a complete typed request to explore page details does the same. A short thank-you receives the authored thumbs-up after an accepted answer. Typing, closing or clearing interrupts the reaction. No animation menu, play/pause button or ball scene is added. Existing bone-white surfaces, Tailwind, provider logos, local-authority carousel and pricing state remain.
